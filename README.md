# Café da Horta — com Maria Alice & Jade

Jogo de restaurante para navegador, feito para iPhone (tela deitada).
Plante e colha na horta, compre no mercado, prepare sanduíches, saladas e sucos
conforme as comandas, e cuide da Jade, a porquinha-da-índia ajudante.

**Jogar:** abra o link do GitHub Pages no Safari e use *Compartilhar → Adicionar à Tela de Início*.

Feito com HTML, CSS e JavaScript puros, sem dependências.
